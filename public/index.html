TasteBrief

Name 2–5 things you already love — an artist, a film, a restaurant, a place, in any mix. TasteBrief resolves them in Qloo's taste graph, walks the connections, and briefs you on what to watch, hear, eat and visit next. Every pick is labelled with the taste thread it hangs from.

No bluffing: every recommendation below comes from a live Qloo call. A domain with no grounded result is left out — never filled in.

Built on the Qloo Taste AI API — entity search, cross-domain Insights recommendations with explainability, and trending — called server-side only (the API key never reaches your browser). Open source under the MIT licence. A Qloo Agentic Hackathon project by Nenzy Brown.
